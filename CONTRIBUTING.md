# Contributing to Python Programming Fundamentals for Life Scientists

Thank you for considering contributing to this open-source resource! 

## 🛠️ How You Can Contribute

1. **Fix Typos & Formatting:** Correct typos, fix broken Markdown links, or refine explanations in the `/chapters` directory.
2. **Add Biological Examples:** Propose additional life science use-cases (e.g., parsing PDB headers, sequence alignment examples).
3. **Submit Bug Fixes:** Fix syntax issues or update outdated library calls in script examples.

## 🚀 Submission Steps

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/new-bio-example`).
3. Commit your changes with clear descriptions (`git commit -m "Add FASTA quality score parsing example"`).
4. Push to your branch (`git push origin feature/new-bio-example`).
5. Open a **Pull Request (PR)** against the `main` branch.
